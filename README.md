# Hi, I'm N Umesh

AI-focused full-stack developer who enjoys turning messy documents into structured, reviewer-friendly HTML. I blend FastAPI backends, React-based tooling, and ML/LLM powered helpers to automate editorial workflows.

## What I'm Building
- **PDF to HTML AI pipeline** - Multi-step converter with GPT-5 Vision, MathML/iMathEQ editing, DaisyDiff previews, and PostgreSQL-backed version history.
- **Automated QA helpers** - LanguageTool integration, grammar checks, and change summaries so reviewers can focus on real issues.
- **Reusable frontend utilities** - Split preview panes, diff viewers, and editor widgets that stay independent of `app.js`.
